第 0 件 · llm.ts

先能问到模型

没有 llm.ts，你连模型都问不到。循环还没转，对话已经断了。

这一件为什么在

模型在网线那头。请求怎么拼、SSE 怎么拆、半截的工具参数怎么粘，都必须停在这一层。上层只收四种事件，不要去碰 HTTP。

对外交出什么

stream：Context 进，StreamEvent 出。事件只有 text_delta / tool_call / done / error。只接 OpenAI 兼容口。

装进工具箱

把四种事件名写进框里。不想手打就点「填入范例」。

llm.ts 已在工具箱。右侧那一份会留下来。

第 1 件 · agent.ts

让模型用得上工具

没有 agent.ts，模型不能用工具。它说「去读这个文件」，然后就停了。

这一件为什么在

模型会吐字，也会点名要工具。一次 stream 结束就散了——结果回不来，它也不能再想一轮。

对外交出什么

runAgent：拉 stream；若是 tool_call，执行、把结果追加进 Context、再问；直到 done。

第 2 件 · tools.ts

四个纯函数干活

没有 tools.ts，循环空转。模型点了名字，没人干活。

这一件为什么在

循环只会调度。读、写、改、跑命令必须是四个纯函数。它们不认识 Context，也不认识循环。

教学剂，没有批准。生产里要有人点头；这里故意卸掉，只看数据怎么流。

对外交出什么

read_file / write_file / edit / run_bash。收参数，回字符串。

装进工具箱

写下四个工具名。不想手打就点「填入范例」。

tools.ts 已在工具箱。四个函数不读循环。

第 3 件 · tui.ts

屏幕只认 AgentEvent

没有 tui.ts，循环在黑盒里转。你看不见字，也拦不住它。

这一件为什么在

人要看见字。终端只该听 AgentEvent：模型在说、工具在跑、这一轮完了。HTTP、SSE、供应商字段，一概不进屏幕层。

对外交出什么

attachTui：读一行输入，按 AgentEvent 往终端写。它不认 HTTP。

第 4 件 · cli.ts

胶水，加上一本账

没有 cli.ts，零件散落。会话也不落盘，一关终端就忘。

这一件为什么在

五个文件不会自己握手。要有人读配置、把人那一行塞进 Context、把 AgentEvent 转给屏幕、每轮把消息追加进 session.jsonl。

对外交出什么

胶水本身。依赖单向：cli 认识所有人；tools 不认识 agent。
