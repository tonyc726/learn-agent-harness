这三晚怎么读橙皮书

橙皮书讲的是缰绳工程学的一般方法，不是另一本 Agent 百科。三晚只对照三节，不要通读，更不要把 PDF 正文贴进仓库。

  • §01：说明书与边界。对应今晚——它只做什么。
  • §04：出错就加规则。对应明晚——硬约束上锁。
  • §10：反馈与验收。对应后天——独立检查，不自审自批。

先走 Track A。Pi、Codex、dsh、老金50篇、Claude sourcemap 还原，都放到 Track B 或更后。Claude Code 官方仓库只有 changelog 与 plugins，没有可对照的公开循环。
