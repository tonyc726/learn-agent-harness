学的是 harness

从零造一个循环

模型只会说话。循环、工具、界面是你写的。写完这五个文件，你就写过一遍最小 harness。

打完工具箱里会有什么

  1. llm.ts：Context 进，四种事件出。只接 OpenAI 兼容口。
  2. agent.ts：stream → 工具 → 写回 → 再问，直到 done。
  3. tools.ts：四个纯函数。教学剂，没有批准。
  4. tui.ts：只认 AgentEvent，不认 HTTP。
  5. cli.ts：胶水 + session.jsonl。依赖单向。
