学的是 harness

别把模型当成整个 Agent

模型会说话；真正改系统的是你在外面加的规矩。那套规矩叫 harness。

打完你会什么

  1. 说明书写清：它只开门禁，不许发版。（system_prompt）
  2. 危险动作只能申请，你点确认才提交。聊天里说「开了」不算。
  3. 密钥、token 不准进对话。模型只看干净摘要。
  4. 有人改过规则，旧确认作废。批准的必须是你看见的那一版。
  5. 构建/通知和对话不是一回事。对话停了 CI 还在；断了去对账，别瞎重试。

CI「红了先通知你、不要自动发版」只是练习用的假任务。你要学的不是 Jenkins，是怎么给模型套缰绳。
