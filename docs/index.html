学的是 harness

从零造一个循环

模型只会说话。下面五个文件是最小 harness。往下读，右边的代码会跟着长出来。

开始读 完整版对照

数据流

用户 → tui → cli → agent → llm

  1. 用户
  2. tui.ts
  3. cli.ts
  4. agent.ts
  5. llm.ts

有 tool_call 就走 tools.ts，把结果写回，再问。每轮结束，cli 把消息追加进 session.jsonl。

五个文件

读到哪一份，工具箱就亮哪一份

  • 01 llm.ts

    Context 进，四种 StreamEvent 出。只接 OpenAI 兼容口。
  • 02 agent.ts

    runAgent：stream → 工具 → 写回 → 再问，直到 done。
  • 03 tools.ts

    read_file / write_file / edit / run_bash。教学剂，没有批准。
  • 04 tui.ts

    只认 AgentEvent，不认 HTTP。换成网页，agent 不用改。
  • 05 cli.ts

    胶水 + session.jsonl。cli 认识所有人；tools 不认识 agent。

怎么读

一篇长文，不是闯关

  • 打开阅读页，往下滚。读到哪一份，右边（手机上是底栏）工具箱就亮哪一份。
  • 想停在某一份，点工具箱上的锁。锁和上次打开的文件记在本机，不记分数。
